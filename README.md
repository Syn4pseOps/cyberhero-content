# ข่าวของ cyberhero.or.th

repo นี้เก็บ**เฉพาะข่าวที่เผยแพร่แล้ว** (`news/<slug>.json` + รูปใน `news/<slug>/`)
ระบบหลังบ้าน Cyber Hero Portal เป็นผู้เขียนไฟล์เมื่อบรรณาธิการกดเผยแพร่ แล้ว workflow
`Deploy website` สั่งเว็บไซต์ (Syn4pseOps/cyberhero-web) สร้างหน้าใหม่ภายในประมาณ 2 นาที

- รูปแบบไฟล์และกฎทั้งหมด: `docs/NEWS.md` ใน repo เว็บไซต์
- แก้ด้วยมือได้ แต่ควรแก้ผ่านระบบหลังบ้าน (มีขั้นตอนตรวจ และบันทึกว่าใครทำอะไร)
- ห้ามใส่ข้อมูลส่วนบุคคลหรือรูปเด็กที่ไม่มีความยินยอมของผู้ปกครอง (repo นี้เป็นสาธารณะ)
